# Jalla Jagannadharao — portfolio
Static HTML/CSS/JavaScript portfolio and printable HTML resume for a 2026 CSE (AI & ML) graduate. Open to relocation across India.

Serve locally with `python -m http.server 8000`. Inspect desktop/mobile navigation and print resume.html before exporting a new PDF. The old resume.pdf is preserved and may contain outdated claims; resume.html is the editable source.

Project reliability/evaluation changes are under review in their respective repositories. No benchmark results or production-readiness claim is made here. Internship details are user-supplied and should match the underlying certificates.
